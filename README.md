# Norrgläntan

## Beskrivning
Norrgläntan är en fiktiv webbplats för ett svenskt naturresmål. Webbplatsen ger besökaren information om områdets natur, aktiviteter och hur ett besök kan planeras.

## Funktioner 
- Presentation av Norrgläntan
- Kontaktuppgifter 
- Information om aktiviteter och om att planera ett besök 
- Responsiv layout för mindre och större skärmar

## Tekniker som använts
- HTML
- CSS
